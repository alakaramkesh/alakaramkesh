### 🚀 Projects

- 🤖 [**Hybrid RAG Chatbot**](https://github.com/wbiegowska/RAG-project): a chatbot that answers from both documents (Docling + ChromaDB) and a database (text-to-SQL on SQLite). *Team project with [@wbiegowska](https://github.com/wbiegowska).*
  <br>🔧 **My part:** query router, text-to-SQL, conversation memory, chat interface
- 🎙️ [**Phoneme Analysis Pipeline**](https://github.com/alakaramkesh/speech-phoneme-analysis-pipeline): compares acoustic features with Whisper and XLS-R representations on a Russian–French L1/L2 speech corpus. XLS-R gave the clearest phoneme clusters (~95% classification accuracy). Reproducible with DVC + Pixi.
- 🔊 [**ASR Robustness Pipeline**](https://github.com/alakaramkesh/asr-noise-pipeline): wav2vec2 evaluated across 7 noise levels (0–30 dB), tracked with DVC.
- 🌍 [**mBERT Zero-Shot Transfer**](https://github.com/alakaramkesh/Multilingual-BERT): POS tagging across 5 languages, 5×5 transfer matrix (94.87% for Italian → French).
- 🧩 [**Dyck Transformer**](https://github.com/alakaramkesh/dyck-transformer): small Transformer trained to detect and correct errors in bracket strings, then probed with OOD tests (99.8% on deeper nesting), a pushdown-automaton baseline, attention rollout, and linear probes. The interpretability results found no clean stack-like mechanism.
- ✍️ [**Character-level GPT (Persian)**](https://github.com/alakaramkesh/REPO-NAME): 6-layer Transformer trained from scratch on a 678K-character corpus; analysis of capacity vs. overfitting.
- 🔢 [**Numerical Precision in wav2vec**](https://github.com/alakaramkesh/numerical_stability): effect of float64/32/16 and int8 quantization on XLS-R embedding geometry. float16 preserved distances at about 4× smaller storage, while int8 added noticeable distortion.
